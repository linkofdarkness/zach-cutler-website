# Contributing to repo-health-checker

Thanks for your interest! Here's how to help:

## 🐛 Reporting Issues

- Check existing issues before filing
- Include the exact command and full output
- Note your Node.js version (`node --version`)

## 💻 Development

```bash
git clone <your-fork>
cd repo-health-checker
npm install
npm start
```

## ✅ Before Submitting

- `npm test` passes
- Code style matches existing files
- Added/updated tests for new features

## 📥 PR Process

1. Fork the repo
2. Create a feature branch (`git checkout -b feat/my-thing`)
3. Commit with clear messages
4. Push and open a PR
5. Keep PRs focused — one change per PR

## 📜 Conventional Commits

We use:
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code change that isn't a feature or fix
- `test:` tests
- `chore:` maintenance
